# Contribuer à pasdevelib-bot

Merci de votre intérêt pour le projet.

## Signaler un bug technique

Ouvrez une [issue GitHub](https://github.com/pasdevelib/pdv-bot/issues) en décrivant :

- Ce qui se passe
- Ce qui était attendu
- Les étapes pour reproduire, si possible

## Proposer une amélioration

Ouvrez une issue avant toute pull request — les évolutions importantes sont discutées en amont.

## Pour les retours sur l'app (pas le code)

Rendez-vous sur [pasdevelib.app/contributions](https://pasdevelib.app/contributions).

## Licence des contributions

En soumettant une pull request, vous acceptez que votre contribution soit publiée sous la même licence que ce projet (PolyForm Noncommercial 1.0.0).

## Ce qu'on n'accepte pas

- Pull requests sans issue associée
- Dépendances lourdes sans justification claire
- Fonctionnalités nécessitant une infrastructure payante
